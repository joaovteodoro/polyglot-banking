# Sistema Bancário em C++

![C++](https://img.shields.io/badge/C++-00599C?style=flat&logo=c%2B%2B&logoColor=white)

Sistema bancário desenvolvido em C++ com orientação a objetos. Permite cadastrar usuários, abrir contas e realizar operações financeiras como depósito, saque e consulta de extrato.

---

## Requisitos

- Compilador com suporte a C++17 (g++ 7+ ou equivalente)

---

## Como executar

Compile o arquivo `main.cpp`

```bash
g++ -std=c++17 -Wall -Wextra -g3 main.cpp -o output/main.exe
```

Execute o programa

```bash
./output/main.exe
```

> Os comandos devem ser executados dentro do diretório cpp\ .
