# Sistema Bancário em Java

![Java](https://img.shields.io/badge/Java-ED8B00?style=flat&logo=openjdk&logoColor=white)

Sistema bancário desenvolvido em Java com orientação a objetos. Permite cadastrar usuários, abrir contas e realizar operações financeiras como depósito, saque e consulta de extrato.

---

## Requisitos

- Java 11+

---

## Como executar

Compile todos os arquivos `.java`

```bash
javac *.java
```

Execute a classe principal

```bash
java Main
```

> Os comandos devem ser executados dentro do diretório java\ .
